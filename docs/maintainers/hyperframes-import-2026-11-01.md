helpers, migration mapping and live-deck integration rather than generic
Remotion authoring or Figma workspace automation.

## Provenance and adaptations

- Each skill root retains the upstream Apache-2.0 LICENSE and full source pin.
  Modified files carry AAS notices. The six bundled WOFF2 fonts retain their
  Inter, EB Garamond and JetBrains Mono OFL notices.
- Nineteen upstream Pixabay recordings are excluded from redistribution and
  replaced by original CC0 procedural cues generated by the included standard
  library/FFmpeg recipe. Historical upstream credits are retained and explicitly
  labelled as referring to excluded recordings. These cues are substitutes,
  not acoustically equivalent recordings.
- Compact metadata, examples, task scope, ignored secret storage, user budgets,
  likeness/voice consent, non-bypass of refusals and default telemetry opt-out
  apply across the references. No silent skill refresh, project-pin upgrade,
  public feedback, subscription or top-up is authorized by installing a skill.
- Fixed the motion gate's empty/non-finite comparison pass and sub-millisecond
  loop hazard; its success describes sampled overlap, not whole-video identity.
- Made the standalone media resolver use published `hyperframes@0.8.226`,
  preserving explicit plugin versions and real monorepo development paths while
  disabling skill refresh in that fallback. The published version was checked.
- Restricted project dotenv imports to provider credential/project identifiers;
  process startup and host-routing variables cannot be injected by project text.
- Rejected parent traversal and absolute/foreign paths for engine media writes.
  This is a lexical path guard, not a hostile-filesystem/symlink sandbox.
- Scoped an upstream monorepo-only test to these complete eight imported trees,
  retaining the optional CLI check when that source exists.

- Skill-local snapshot admission uses pinned upstream links for cross-skill
  plugin guidance; the actual sibling core reference is retained. Source scripts
  are distributed as mode 0644 and invoked explicitly with Node/Python/Bash;
  corpus internal calls and instructions follow that convention.
- Dependency review identified GHSA-mrhx-c7xc-m3w5 in the fixture Zod range.
  The three Remotion fixtures now pin Remotion/CLI 4.0.539 and override direct
  and transitive Zod to patched 4.6.6. The data-driven fixture type-checks with
  TypeScript 5.9.3 and its runtime dependency audit reports zero vulnerabilities.

## Validation and limits

224 bundled Node tests passed with isolated media/config paths, no inherited
provider credentials and telemetry disabled. Tests include real synthetic FFmpeg
motion pass/fail cases, malformed/empty comparisons, standalone argv forwarding,
dotenv isolation and media-path escape rejection. The Python credential suite
passed seven mocked tests; migration clean/blocker smoke and all eight escape
hatch fixtures passed. Every bundled executable was syntax-checked, JSON parsed,
font signature checked and file inventoried with a content hash.

The contribution preflight and protected exact-head CI remain required before
merge. No paid provider, live Figma file, authenticated likeness generation,
cloud deployment, full video migration corpus render or complete end-to-end
native app test was run. Recipes remain illustrative. Literal public-host media
URL checks do not pin DNS and must not be mistaken for network isolation.
General catalog snapshots and plugin mirrors remain release-owned.
