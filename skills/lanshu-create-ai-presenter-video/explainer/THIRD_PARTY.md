# Third-party components

The explainer engine is MIT-licensed with the rest of this repository. It bundles one small font file and loads
everything else at build or render time; nothing below is vendored into the repository except the first entry.

| Component | How it is used | License |
| --- | --- | --- |
| Noto Serif SC (one-glyph subset, `kits/v3-notebook/fix-56de.woff2`) | bundled: replaces ZCOOL XiaoWei's 回 | SIL Open Font License 1.1 |
| Google Fonts families (Noto Sans/Serif SC, ZCOOL XiaoWei, ZCOOL KuaiLe, Long Cang, Caveat, Bangers, Archivo, Instrument Serif, JetBrains Mono, IBM Plex Mono, Geist, …) | subsets downloaded by `tools/fonts.py` into each film | SIL Open Font License 1.1 / Apache 2.0 |
| Smiley Sans 得意黑 (`@chinese-fonts/dyh@3.0.0`) | subset chunks fetched from jsDelivr by `tools/fonts.py` | SIL Open Font License 1.1 |
| GSAP 3.14.2 | loaded from jsDelivr by the DOM styles' films | GSAP standard license (free use) |
| three.js r181 (0.181.2) + addons | loaded from jsDelivr by V6 and V9 | MIT |
| HyperFrames 0.8.81 | run with `npx` to check, snapshot and render | see the HyperFrames project |
| MiniMax T2A | the voice provider called by `tools/story.py` (audio + word timestamps) | the provider's terms |

Procedural textures (`grain.svg`, `paper-grain.svg`, `kits/v8-chalkboard/chalk-mask.png`) and all sound effects are
generated by this project.
