# V9「一柜」· KV cache 黏土版

同一套黏土小城 kit（`kits/v9-clay`），讲 KV cache。一镜到底；讲完拉远，整座城就是复习图，四个区各挂一张编号卡片。

| 比喻（画面） | 真名（配音） |
| --- | --- |
| 写字机器人，一次蹦出一个字块 | 大模型自回归，一次一个 token |
| 新字块沿三根黏土面条回头看前面的字块 | 注意力：新 token 和前面每一个比 |
| 重算台阶：每一步都把前面的卡全做一遍，台阶越堆越高、越做越慢 | 不用缓存：第 n 步重算 n 个 K/V（三角形 ~n²/2） |
| 卡片柜（带脸） | KV cache |
| 黄标签 / 蓝卡片，各做一次（×1）后放进抽屉 | Key（匹配）/ Value（被取走的内容），只算一次、存起来 |
| 新字块的放大镜顺着 K 列查，每行冒出权重条，蓝卡片飞回来 | 只算新 token 的 Q、K、V，再查缓存 |
| 玻璃储藏室；上下文每多 1K，柜子长高一节 | 显存，随上下文线性增长 |
| 一格抽屉拉开成 32 层薄片；公式贴纸 | Llama 2 7B：2 × 32 × 4096 × 2 B ≈ 0.5 MB/token；× 4096 ≈ 2 GB（单条请求） |
| 四个读者（Q1–Q4）共用一套卡，柜子缩成 ¼ | GQA（例：Llama 3 8B 32 个头共用 8 份 K/V） |
| 一大块预留空位拆成活页，用一页给一页 | PagedAttention 按页分配 |
| 卡片变薄，柜子减半 | 量化 FP16 → INT8 |
| 天平：一边显存，一边速度；聚光灯照着最新的字块 | 用显存换速度，只算新的那一个 |

权重条是示意（散射最关注蓝光、空气），不是实测数值。声音：`tools/sfx.py`（读 `lib/story.js` 的词时间）。
