# V10「推演」· KV cache

同一套推演 kit（`kits/v10-reasoning`），讲 KV cache（`stories/kv-cache-reasoning`）。一张画布、四个推演站：每句话都在画布上
“加一步几何”——项随话音写进公式、点一行一行长出来、向量转到位、点从三角形飞进缓存；讲完拉远，整个推演就是一张图，
复习时每一步框住它自己的站。

| 图形（画面） | 真名（配音） |
| --- | --- |
| 颜色绑定的式子 out = Σᵢ softmax(q · kᵢ) vᵢ，每一项在被说到时写进去，引线连到大白话标签 | 注意力：新 token 的 q 和前面每个 k 比，按比例取走 v |
| 玫红 = 新的 / 正在推导的（q、对角线、新的一行）；青 = k、缓存；琥珀 = v；朱红 = 浪费 / 代价 | 三种颜色贯穿全片（字幕里的 q、k、v 也同色） |
| 二维向量盘：q 和每个 k 的夹角，投影 = 点积；越接近取得越多（二维示意） | q·k 打分，softmax 按比例 |
| 点三角形：第 n 行 n 个点，对角线是新算的，左边带 ↻ 的是又算一遍；列线揭示“同一个 token 被算了一遍又一遍” | 不缓存：第 n 步重算 n 份，1+2+…+8 = 36 = 8 + 28 |
| 每个对角点分出青 k、琥珀 v，飞进下面的缓存列；重复的点褪成虚线 | k、v 只算一次，存进缓存 |
| 新 token 只算自己的 q、k、v（×1），k、v 写进最后一行；q 沿 k 列逐行比对，v 按匹配回流到 out | 之后只算新来的一个，再去缓存里查 |
| 两张图：不缓存的点 (n, n) 落到 y = 1；显存线随长度线性上涨，斜率 0.5 MB/token，4096 处 = 2 GB | 每步从 n 份变 1 份；代价是显存（Llama 2 7B） |
| 2 × 32 × 4096 × 2 B ≈ 0.5 MB，每一项引线到 k 和 v / 层 / 维 / FP16 | story.json facts：per_token_bytes、context_4k（单条请求） |

示意值：例句「因为空气把蓝光散射得更多」、二维方向和权重（softmax(2·cos)）只是示意，界面上都标了「示意」。
声音：`tools/sfx.py`（起步模板的底 + 本片 beats 的点、飞行、扫描、落点；读 `lib/story.js` 的词时间）。
