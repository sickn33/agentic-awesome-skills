# 风格契约

## 共通原则

- 把色场当作环境现象，不把它当成组件皮肤或装饰贴纸。logo、头像、分隔线等界面部件保持中性，不用调色板渐变上色。
- 先建立稳定的信息层级：导航、列表/队列、详情、元数据、状态带。
- 让颜色跨越整个场景，但保持文字、边界、按钮和选择态可读。
- 用 OKLCH 编写颜色；为降级路径保留 sRGB 值。
- 颜色数组按色相顺序排列。渲染器把颜色依次排在一条首尾相接的色相轴上，相邻两色在交界处混合；近互补色相邻时，交界处色度互相抵消，只剩变暗。
- 使用连续的 fBm/domain-warp、流带或方向性流域。禁止明显的圆形光斑、中心聚光和硬彩虹条。
- 维持静、薄、净、密、活的工作台气质：表面轻、信息密、状态清楚、背景有生命但不抢语义。

## 流光溢彩白 / `opal`

定位：白色是第一视觉，色彩像被光照亮的珠光薄层，能看到变化但不破坏“白”。

下表按 starter 工作台标定：顶栏、侧栏和工作区等面板以 66%–92% 的不透明度盖在色场上。色场直接露出时，按下一节调整。

| 参数 | 建议范围 | 作用 |
|---|---:|---|
| `overallColorIntensity` | 0.60–0.90 | 控制全局彩色预算，默认约 0.82 |
| `base.oklch.l` | 0.975–0.990 | 保留白色基材身份 |
| `base.oklch.c` | 0.002–0.008 | 只给基材轻微方向，不制造灰雾 |
| 颜色 `oklch.l` | 0.90–0.96 | 让色彩保持浅、薄、透 |
| 颜色 `oklch.c` | 0.030–0.065 | 足够识别，但避免糖果霓虹 |
| `peakOpacity` | 0.055–0.110 | 决定局部峰值，先调它再调总体 |
| `field.warpStrength` | 0.22–0.42 | 让颜色互相流动而非分块 |

白版不使用 `field.luminanceCap`。建议使用玫瑰、海玻璃青、丁香、珠杏、薄荷和远空蓝等低饱和色相。至少让三种色相在同一截图中可辨，不要让整张图退化为普通暖白、灰雾或单一冷白。

### 色场直接露出

个人主页、文章页这类页面没有面板盖住色场，按上表的强度会显得花，也会把整页压暗。下表是一个真实站点在一位用户屏幕上的判断。`tint.p50` 是 `measure_preview.py` 测得的相对底色色偏中位数（OKLab），用用户当时看到的那一版渲染器重新测得；换站点或屏幕需要重新确认。

| 用户判断 | `tint.p50` | 配置 |
|---|---:|---|
| 看不出色场 | 约 0.004 | overall 0.30 |
| 合适：仔细看能看出，不发灰 | 约 0.0056 | overall 0.45 |
| 显得花且乱 | 约 0.009 | 上表默认参数，色相交错排列 |
| 阅读页，接近全白 | 约 0.0017 | overall 0.15 |

那个站点的其他参数：底色 `l` 0.988，颜色按色相排序，`field.scale` 0.8，`octaves` 3，`warpStrength` 0.26。当前渲染器下，这组参数在 overall 0.45 时测得约 0.0052，0.55 时约 0.0063。

白版的颜色都比底色暗，着色的同时一定变暗。同一组颜色下，变暗和色偏按同一比例随强度变化，`shiftToTint` 基本不变，所以降低强度只会让色场更淡，不会让它更干净。要减少发灰，先按色相排序并检查 `grayRatio`。把颜色亮度调得更接近底色也能减少变暗，但越接近白色，sRGB 能容纳的色度越小；这一点还没有在当前渲染器上实测。

## 五彩斑斓黑 / `obsidian`

定位：黑色是基材，彩色是沉在黑里的光谱现象；多色可见，但亮度必须受控。

| 参数 | 建议范围 | 作用 |
|---|---:|---|
| `overallColorIntensity` | 0.80–1.00 | 允许色相进入暗场，默认约 1.00 |
| `base.oklch.l` | 0.070–0.130 | 保留黑色基材身份 |
| `base.oklch.c` | 0.006–0.018 | 只给黑底轻微冷向 |
| 颜色 `oklch.l` | 0.18–0.34 | 控制暗彩的可见层级 |
| 颜色 `oklch.c` | 0.035–0.075 | 使色相可辨但不变霓虹 |
| `peakOpacity` | 0.14–0.32 | 暗场中色彩的局部峰值 |
| `field.warpStrength` | 0.30–0.50 | 形成连续暗流 |
| `field.luminanceCap` | 0.12–0.19 | 防止黑版被抬成灰版 |

建议覆盖深潮青、石油蓝绿、海军蓝、暗靛、紫影和氧化暗金。确保至少五种色相在校准截图中有测得覆盖；不要只剩青黑、死黑或一圈彩色边。

## 参数解释

- `intensity`：该色相参与场的权重，必须可被滑杆实时改变。渲染器把它和 `peakOpacity` 相乘，作为该色相的强度。
- `peakOpacity`：`intensity` 为 1 时该色相的强度，是校准时定下的值；不要把它误写成整个页面透明度。
- `fieldScale`：该色相的空间频率；不同值能避免所有颜色同相叠加。
- `phase`：确定性相位，长度为 2 的数组；同一 seed 下保持稳定。
- `ditherStrength`：输出码值上的三角抖动幅度，以一个色阶为单位。1 能消除量化偏差；小于 1 会留下一部分偏差，强度越低越明显。
- `luminanceCap`：只在黑版生效，限制混色后的线性亮度。
- `measuredCoverage`：相对底色的色偏超过可见阈值、并按偏离方向归属该色相的像素块占比。
- `effectiveShare`：可见色偏能量中该色相的相对份额；这是近似归属，不是 shader 内部精确贡献。
