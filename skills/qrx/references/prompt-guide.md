# QRX prompt guide

A QRX prompt describes only the picture. Formula: **subject + setting + style or medium + palette + mood**, in 10 to 30 words.

## Examples by use

| Use | Prompt |
| - | - |
| Café menu | a steaming flat white on a timber bench, morning light, watercolour, warm cream and espresso brown |
| Surf club poster | a curling turquoise wave at dawn, Japanese woodblock print, navy, teal and sand |
| Florist packaging | a bunch of native waratahs and banksias, botanical illustration, crimson and sage green |
| Tech conference badge | a glowing circuit-board city at night, isometric 3D, electric blue and magenta |
| Wedding invitation | climbing white roses on a stone arch, soft pastel gouache, ivory and blush pink |
| Winery label | rolling vineyard hills at golden hour, linocut print, burgundy and gold |
| Kids' event flyer | a friendly cartoon koala in a hot-air balloon, bright flat illustration, primary colours |
| Real-estate sign | a modern house with a pool at dusk, architectural rendering, charcoal and warm amber |

## Fixes

| Problem | Change |
| - | - |
| Art looks busy or muddy | One subject, drop secondary objects, add "bold shapes, clean composition" |
| Code hard to scan when printed small | Ask for "high contrast, strong light and dark areas"; print larger |
| Colours off-brand | Name colours in plain words ("forest green, cream"), two or three at most |
| Unwanted text or letters appear | Remove any mention of words, signs, labels or typography |
| Looks generic | Add a specific medium and era: "1930s travel poster", "risograph print" |

## Brand fit

Ask the user for their brand colours, two or three adjectives for the brand voice, and where the code will appear. Translate these into palette and style words. Never include logos, wordmarks or mascots in the prompt; place the brand logo beside the code in the final layout instead.
