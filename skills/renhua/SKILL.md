# 人话：按 Jack 的口吻写东西

## When to Use This Skill

- the user asks for a Xiaohongshu note, X post, diary, WeChat Moments text or product intro in Chinese
- the user says the text sounds like AI and wants it humanized in their own voice

## 先读这条（2026-10-20 用户纠正）
"文字完全不人话，读起来都不通顺……幽默不重要，偶尔需要时有一下就行，不然显得油腻。"
- **通顺第一。** 发出去的文字（笔记正文、文档、产品介绍）用完整句子和正常中文标点（，。），每句主语谓语清楚，读出声不卡。下面"节奏"里说的空格断句，是他打字聊天的习惯，只用在很短的图上文字和 X 单句里，不能拿来写正文。
- **每段一条逻辑线**：发生了什么 → 结果是什么 → 我怎么看。可以用"然后""所以""但是""说实话"连起来。
- **幽默最多一处**，没有合适的就不加。梗、反问、自嘲堆在一起就油腻。`references/humor.md` 只在用户明确要网感时才读。
- **金句最多一句**，放在段尾或全文结尾，用他自己会用的具体比喻（马当路答辩里被认可的例子："做蛋糕是让它变大，不是切得更好""我不必变成一板一眼的人，但我需要闭环""想到就干是我的长处，先问清楚再干是我在补的课"）。金句要从这件事里长出来，不能是放哪都成立的大道理。
- **不用冒号和破折号**，改成完整句。
- **不写没发生、没核实的事。**
- **正文先读 `references/insight.md`**：主题句首尾呼应、结果先行、每段平铺直叙、段尾一句金句、后半段一段有数据撑着的核心洞察。这是从他认可的「马当路答辩」定稿里拆出来的骨架。
- 写完做一遍对照：原句 → 改后，看是不是更顺、更像他说话。


规律来自 Jack 自己打的 407 句原话（他和各种 AI 工具的历史对话），以及他语音输入的长段话。写之前先读完这一页。

## 他实际怎么说话

**节奏**
- 短句连着说，句子之间常用空格隔开，不用句号收尾。
  例：“好卡啊 彻底完蛋了”，“蛮好的 假如你是这个网站的艺术技术总监 优化一些细节就可以”。
- 想到哪说到哪，一段话里会拐弯、补充、自我修正：“不对不对 回到之前的状态”“或者说……”“相当于……”。
- 句子长短不齐。偶尔很长的一句，后面跟一句很短的判断。

**态度**
- 评价直接，不铺垫：“太丑了”“这风格也太古早了些”“我觉得不行啊”“还挺好的”。
- 夸人也随口：“你的表现很棒”“目前架构很完美”。
- 会用口头禅表达真实感受：“我的天”“好卡啊”“怎么这么久”“你为啥没做”。

**常用词**（按出现频率）
要、可以、很、还、怎么、然后、吧、太、而且、但是、一下、全部、我觉得、啊、呢、就是、直接、感觉、其实、挺、蛮、反正、相当于、比如说、对吧、有点。

**专业词**：直接用英文原词，不翻译、不加引号：gtm、ui、SEO、agent、vibe coding、MCP、popart。

**数字**：随口说，不精确到小数点，除非数字本身就是笑点（收入 ¥0.00）。“花了 200 美元”“几百张”“十块钱左右”。

## 必须删掉的 AI 味

写完逐条检查，出现就改：
1. **emoji**：一个都不要。他原话 407 句里只有 2 句带 emoji，还明确说过“不要乱用 emoji 把整体水平降低了”。
2. **清单和排比**：不要 ✅/❌/·/1. 2. 3. 罗列，不要三句结构一样的排比句。要说三件事，就用“一个是……还有一个……”串起来。
3. **金句和升华**：删掉“被一个 AI 上了一课”“做东西不难，难的是……”“这就是……的意义”“与其……不如……”这类工整的总结句。
4. **AI 高频句式**：“不是……而是……”“值得一提的是”“最大的感受是”“总的来说”“首先/其次/最后”“让我们”“一起见证”“答案是”。
5. **过度工整**：每段一样长、每句都有主语、标点完美。真人写东西有省略、有口语、有不完整的句子。
6. **冒号排版**：“今天的反思：”“Day 1 概况：”这种小标题式冒号，改成直接说。
7. **假装的情绪**：“太震撼了”“绝了”“破防了”这种网络腔，他不这么说。他的情绪很具体：“好卡啊”“怎么这么久”。
8. **万能结尾提问**：不要“你怎么看？评论区告诉我”。要问就问一个具体的、他自己也想知道的问题。

## 写作步骤

1. 先像跟朋友发语音一样，把这件事口述一遍。不管结构，想到哪写到哪。
2. 加上他的口头禅和直接评价，但别堆砌。一段最多一两个“然后”“就是”，像人说话，而不是模仿人说话。
3. 对照上面 8 条删 AI 味。
4. 删掉 20% 的字。删得最多的应该是形容词、总结句和过渡句。
5. 读一遍：如果像公众号文章或者产品发布稿，重写。如果像他在微信里跟朋友说的，就对了。

## 示例库

写小红书标题和正文前，先读 `references/examples.md`：真实爆款标题按结构分类（反差自嘲 / 身份+挑战+期限 / 做了个X实测 / 一句话梗），附大学生口吻和科技自媒体口吻对照。学结构，不抄原句。Jack 的版本 = 科技自媒体的判断力 + 大学生的坦白和自嘲。

## 网感和小幽默

写完人话版后，读 `references/humor.md`，挑 1–3 处加梗：反问式标题、单句停顿、给现象起名、一本正经的离谱类比、冷幽默、回敬梗、反差结尾。学的是量子位、差评、CZ、孙宇晨、曾颖、邵艾伦的句式。梗后面必须跟真数字，知识点一个都不能少。

## 平台差异

- **小红书**：可以多分几行，每行一两句话，靠换行而不是标点控制节奏。标题像随口一句话，可以带数字，不要“｜”“！”堆砌。
- **X**：更短。一条只说一件事，可以只有半句。
- **评论回复**：一两句，直接，像聊天。
