# UI Nanobanana — Taste + Impeccable + Nano Banana (2K/4K OP Edition)

## Overview

`ui-nanobanana` prevents AI coding agents from producing generic, templated frontend code ("AI slop") or empty placeholder pages by combining three systems into one deterministic workflow:

1. **Impeccable Deterministic Guardrails (`DESIGN.md` + `PRODUCT.md` + 58 Anti-Slop Rules)** — Locks brand tokens, surface mode (`Persuade`, `Operate`, `Read`, `Experience`), voice, and explicit `anti_references` before a single component or image is created, backed by 18 sub-commands (`/ui audit`, `/ui normalize`, `/ui polish`, `/ui typeset`, `/ui animate`, `/ui bolder`, `/ui quieter`, `/ui overdrive`, etc.).
2. **Taste Skill Art Direction & Copy Arithmetic** — Enforces a **Subject Inventory** (8–12 specifics unique to the client), the **Competitor Test**, **One Live Thing** (a real interactive micro-instrument on the page), **Two-Line Headline Arithmetic** ($\le 32$ chars for Hero `h1` across `1440px`, `768px`, and `390px`), and **Combinatorial Composition Variety** (no default left-text/right-image hero; no two neighboring sections sharing a layout).
3. **OP High-Resolution Nano Banana & Gemini 4 Visual Pipeline** — Syncs `DESIGN.md` into `generations/refs/brand/style.md`, presents one upfront **Batch Media Plan & Cost Quote**, generates the **2K/4K Hero plate first** on **Nano Banana 2.1** (`gemini-nano-banana-2.1`) or **Nano Banana Pro** (`gemini-3-pro-image`) with engineered negative-space safe zones for UI typography, and passes that approved Hero into every subsequent call (**Series Lock**), **Gemini Omni 1.2 Flash** (`gemini-omni-1.2-flash`) starting-frame video loops, and **Gemini 4 Carbon / Argon / Neon / Hydrogen** (`gemini-4-carbon`, `gemini-4-argon`, `gemini-4-neon`, `gemini-4-hydrogen`) SVG/Three.js/GLSL shader code visuals.

Adapted from [AntonioCardenas/ui-nanobanana](https://github.com/AntonioCardenas/ui-nanobanana), building upon [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), [pbakaus/impeccable](https://github.com/pbakaus/impeccable) ([Dominando Impeccable guide on yeou.dev](https://www.yeou.dev/articulos/dominando-impeccable-skill/)), and [AntonioCardenas/generate-nanobanana](https://github.com/AntonioCardenas/generate-nanobanana).

## When to Use This Skill

- Use whenever building, designing, redesigning, auditing, normalizing, or polishing a website, landing page, portfolio, product page, dashboard, or app screen in any stack (Angular, React, Next.js, Astro, Vue, Svelte, HTML/CSS, Tailwind, GSAP, Lenis).
- Use when a user says a UI looks generic, templated, "AI-made", or needs cohesive 2K/4K studio visuals locked to their design tokens.
- Use when invoking `/ui init`, `/ui craft`, `/ui visual-plan`, `/ui audit`, `/ui normalize`, `/ui polish`, `/ui typeset`, `/ui colorize`, `/ui layout`, `/ui animate`, `/ui bolder`, `/ui quieter`, `/ui distill`, `/ui harden`, or `/ui overdrive`.

## How It Works

1. **Surface Mode & Contract (`PRODUCT.md` & `DESIGN.md`)** — Classify the surface (`Persuade`, `Operate`, `Read`, `Experience`), compile the 8–12 item **Subject Inventory**, and synchronize `DESIGN.md` tokens and `anti_references` into `generations/refs/brand/style.md` (see [`references/design-contract.md`](references/design-contract.md)).
2. **Argument, Two-Line Copy Math & Composition Matrix** — Structure sections as **Claims -> Proof**, verify every `h1`–`h6` fits in $\le 2$ lines at `1440px`, `768px`, and `390px`, choose a non-default Hero Scale and varied per-section Composition Anchors, and design **One Live Thing** (see [`references/art-direction-and-copy.md`](references/art-direction-and-copy.md)).
3. **Upfront Batch Media Plan & Hero-First Series Lock** — Present one consolidated Batch Media Plan Table quoting all 2K/4K Nano Banana plates, panoramic dividers (`21:9`, `4:1`), Omni 1.2 Flash video loops, and Gemini 4 Argon/Neon/Hydrogen code visuals. Wait for explicit user approval, then generate sequentially one at a time, passing the approved Hero plate as a reference into all subsequent section plates and logging `.json` sidecars (see [`references/nanobanana-visual-pipeline.md`](references/nanobanana-visual-pipeline.md)).
4. **58-Rule Deterministic Audit & Multi-Viewport Polish** — Verify `0 FAIL` across all 58 anti-slop rules (`SLOP-01` through `SLOP-58`) at `1440px`, `768px`, and `390px` (see [`references/anti-slop-58-rules.md`](references/anti-slop-58-rules.md) and [`references/commands-playbook.md`](references/commands-playbook.md)).

## Examples

### Example 1: Full Page Art Direction & Batch Media Plan (`/ui craft`)

```
User: /ui craft a landing page for our minimalist Solarpunk architectural studio on a #0c1624 dark base
```

The skill reads or creates `PRODUCT.md`, `DESIGN.md`, and `generations/refs/brand/style.md`, compiles an 8–12 item Subject Inventory, writes the two-line headlines ($\le 32$ chars for `h1`), designs **One Live Thing** (an interactive material switcher), and presents one upfront **Batch Media Plan Table** quoting the 4K Hero plate (`gemini-3-pro-image`) and Series-Locked 2K section plates (`gemini-nano-banana-2.1`) before generating sequentially and writing `.json` sidecars.

### Example 2: 58-Rule Deterministic Audit (`/ui audit`)

```
User: /ui audit src/app/landing/landing.component.html
```

Scans the component template and styles against all 58 deterministic anti-slop rules (`SLOP-01` through `SLOP-58`), reporting any banned purple/indigo gradients, eyebrow badges, 3-card icon rows, headlines wrapping past 2 lines, or missing image dimensions without modifying code until `/ui polish` is requested.

## Best Practices

- ✅ Define or sync `DESIGN.md` and `generations/refs/brand/style.md` before generating UI code or images so CSS tokens and Nano Banana 2K/4K plates share one palette and lighting world.
- ✅ Present the consolidated Batch Media Plan Table with itemized and total USD cost estimates and wait for explicit user approval before running paid Gemini API calls.
- ✅ Generate the 2K/4K Hero plate first and pass it in `reference_images` (or chain via `previous_interaction_id`) for all subsequent section plates (**Series Lock**).
- ❌ Don't default to a left-text / right-image hero, three identical icon-in-a-square feature cards, eyebrow pills, or `01 / 02 / 03` decorative numbering.
- ❌ Don't overlay HTML typography on a high-contrast photo without engineering a negative-space safe zone in the prompt and applying a palette-locked tonal scrim (`>= 4.5:1` contrast).

## Limitations

- Paid media and reasoning calls (`gemini-nano-banana-2.1`, `gemini-3-pro-image`, `gemini-3.1-flash-lite-image`, `gemini-omni-1.2-flash`, `gemini-4-carbon`, `gemini-4-argon`, `gemini-4-neon`, `gemini-4-hydrogen`) require a `GEMINI_API_KEY` and spend against Google AI Studio billing.
- No Gemini image or video model documents a `seed` parameter on the Interactions API; visual consistency across sections relies on **Hero-First Series Lock** (`reference_images`), `previous_interaction_id`, and verbatim `style.md` anchors rather than deterministic seeds.
- Static code auditing (`/ui audit`) catches structural and CSS anti-patterns (`SLOP-01` to `SLOP-58`), but final multi-viewport verification (`1440px`, `768px`, `390px`) should always be inspected in a real rendered browser.

## Common Pitfalls

- **Problem:** Generating 6 independent section images that look like an incoherent scrapbook.
  **Solution:** Always generate Slot 1 (Hero) first, then pass that approved Hero image file in `reference_images` along with `generations/refs/brand/style.md` for Slots 2..N.
- **Problem:** Display headlines wrapping to 3 or 4 lines on mobile (`390px`) or split desktop columns.
  **Solution:** Use the Two-Line Headline Arithmetic ($\le 32$ chars / 4–6 words for `h1`) with `max-width: XXch` and `text-wrap: balance`.

## Security & Safety Notes

- **Network** — Paid media/reasoning calls go strictly to `generativelanguage.googleapis.com` via Google's official `google-genai >= 3.2.0` SDK.
- **Secrets** — `GEMINI_API_KEY` is only ever read from the environment or an existing workspace `.env`; never written, logged, or committed.
- **File writes** — Confined to the active project workspace (`DESIGN.md`, `PRODUCT.md`, project source/asset folders, and `generations/`).
- **Cost Gate** — Every paid batch or single asset edit quotes expected USD cost from live Google AI Studio pricing and waits for explicit user approval before running sequentially.
