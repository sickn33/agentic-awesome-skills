# 12 开源与上架

读完产出：`docs/ship-checklist.md`。门槛：下面每项勾选并附证据。

## 开源前
- [ ] 全仓搜密钥/令牌/邮箱/手机号/真实姓名/证件/内部路径：`git grep -nEi "key|token|secret|password|@gmail|@qq|sk-"`，历史也要查。
- [ ] 个人或公司的域名注册信息、付款信息、私聊内容不进仓库（私有文件放 `.gitignore` 的 private/）。
- [ ] 第三方素材（参考图、截图、竞品图）不进仓库和成品；`refs/` 加入 `.gitignore`。
- [ ] 字体、图标、音效、模型逐个核对许可证，放 `Licenses/`；只用 OFL/MIT/Apache 等可分发的。
- [ ] 许可证选定（代码）与素材授权单独说明。
- [ ] README：一句话、动图、安装、目录、哪些已验证哪些没验证。
- [ ] 仓库名/About/topics/Release 由用户确认；**发布到 GitHub 由用户本人批准**。
- [ ] 收录与曝光：awesome 列表 PR、Product Hunt（周二至周四）、Reddit 自荐版先读版规。

## App Store
- [ ] Bundle ID（首次上传后不可改）、团队 ID、App Group、通用链接 AASA。
- [ ] 隐私清单 `PrivacyInfo.xcprivacy`、数据收集问卷、权限文案逐条真实。
- [ ] 订阅：条款与隐私链接真实可打开、价格加载失败有重试、恢复购买、StoreKit 测试配置。
- [ ] 截图：用 06 的海报版式；至少 3 个核心屏；本地化文案由母语者校对。
- [ ] 关键词/副标题按目标区本地化；检查同名 App。
- [ ] 无障碍与动态字体通过 `apple-design` 审查。
- [ ] 提审备注写清测试路径；不依赖未上线的服务。
- [ ] 账号、开发者费用、提审按钮：用户本人。

## 商业与开源并存
App Store 付费版+开源代码可以并存（注意许可证与素材授权）；开源主要换热度、比赛与资源，收入另算。
