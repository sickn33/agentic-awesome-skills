# 错误账本（症状 / 根因 / 正确做法 / 以后怎么检查）

来自 16 个 UI 版本、一次品牌从零搭建、多次发布视频的真实返工。每条的"检查"是一个可以现在就执行的动作。

| # | 症状（用户怎么说） | 根因 | 正确做法 | 检查动作 |
|---|---|---|---|---|
| 1 | "自评每项 8 分，用户说 UI 丑、像 web" | 自评分没有外部参照，只衡量"改了多少" | 截图与具体参考作品并排，写"哪里不如它"，分数仅作参考 | `ui-log.md` 本版有 ≥3 行具体"不如它"，且没有 N/10 当结论 |
| 2 | "又土又丑，像 web，一点都不像 SwiftUI" | 只用静态 Shape+描边，没用平台表现力；结构是竖滚版块+说明文字 | 先做诊断三问（结构/表现力/素材），用 shader、Canvas、几何转场、手势 | 方案页列出本屏用到的 ≥2 项平台能力 |
| 3 | "字体怎么还不是 doodle / 字体不对" | 把风格化只做在图形上，文字用系统体或被否字体 | 为每种语言定标题/正文/批注字体写进 token，被否字体进"不要" | 全局搜索硬编码字体名；与 style-bible 字体表对照 |
| 4 | "落流长猫大说连绕影飘看不懂" | 一字按钮谜语 UI，为了"设计感"牺牲可读 | 字必须读得懂；用图+手势表达，减少文字 | 每个可点元素问"第一次见的人知道是什么吗" |
| 5 | "方方正正圆圆角角让 UI 很丑" | 圆角矩形/胶囊是默认值，没换设计语言 | 不规整来自剪纸轮廓、团块、歪放、胶带，不是线条抖 | 截图里 grep 圆角矩形：全局搜 `RoundedRectangle/Capsule` 数量降为系统 sheet 之外为 0 |
| 6 | "每个控件都套粗黑描边，像网页新粗野主义" | 把"手绘"理解成"加粗描边" | 颜色从不描边；线只用于画画与下划线 | 参考卡里的"颜色不描边"规则逐屏核对 |
| 7 | "退回原生毛玻璃+系统字体，被否" | 被批评后矫枉过正，整个回到默认 | 保留风格方向，只修具体问题；用户说"回到某版"≠换方向 | 改动前列"保留/修改"两栏给自己看 |
| 8 | "同一张照片/素材铺满，看久了单调" | 偷懒用一个素材，没做多样化 | 素材库多样（全身/半身/风景/不同裁切/不同纸色） | 一屏内相同素材 ≤1 次；素材清单有≥6 种 |
| 9 | "你的人物实在太丑了" | 代码画角色/用丑素材 | 角色用生图或真实资产；代码只做排版与效果 | `asset-list.md` 每项标注"谁生成" |
| 10 | "你没用好我给的参考" | 把视觉参考当功能参考，或只看了一两张 | 严格区分视觉/功能；每张反推提示词存档；融合成一套 | INDEX.md 卡片四项全填；方案里引用卡片编号 |
| 11 | "React Bits 你没好好看吧" | 只读了链接标题，没拆机制 | 逐个打开 demo，写"抓到的机制/用不用/为什么"的表 | 研究表 ≥8 行，每行有机制，不是链接 |
| 12 | "越改越差、卡得要死、空转" | 上下文极大（近百万 token、上百张内嵌图），从未压缩；上行网络差 | 里程碑处写 CLAUDE.md，新开会话；调低压缩阈值；截图比完写成文字 | 会话 >300 回合或卡顿 → 写交接块并建议新会话 |
| 13 | "先做功能，风格后补，全部返工" | 顺序错误 | 功能地图 → 风格圣经 → 预览 → 代码 | `phase_gate.py` style 阶段 PASS 之前不写 UI |
| 14 | "你没出预览就直接写代码" | 省一步，结果方向错 | 口味问题先 2–3 个静态预览，带推荐 | `ui-log.md` 本版节首有预览截图路径 |
| 15 | "第 5 版还在叠补丁" | 沉没成本 | 第 3 版仍被否就停，写诊断和新方案 | 同一屏被否次数 ≥3 → 暂停写 `plan.md` |
| 16 | "权限被拒显示已保存" | 失败路径没设计 | 失败如实提示+补救按钮+warning 触感 | QA 状态矩阵里"权限被拒"一栏有截图 |
| 17 | "说明框盖住图片，不滑不消失" | 教学浮层与内容争抢 | 一行提示放图下方，2 秒淡出，首次真滑动时演示 | 首次打开截图里中央无遮挡物 |
| 18 | "价格一直加载/按钮永远灰" | 没做超时和出错状态 | 8 秒超时+重试；条款与隐私链接真实 | 断网下走一遍付费页 |
| 19 | "4 套视觉并存，新旧不统一" | 只改了一屏，其他沿用旧组件 | 先统一组件，再逐屏换；死代码删除 | `grep` 旧组件名无引用；旧屏有入口才保留 |
| 20 | "颜色常量 35 个，同义不同值" | 无 token 约束 | 一个语义一个 token；UIColor 从 Color 派生；间距走网格 | 视图中 `Color(red:`、写死间距数量 → 0 |
| 21 | "展示的是 20 年前手机照/素材丑" | 素材来路随意 | 用高审美现代素材；留白胜过丑素材 | 视频/海报前先看素材联系表 |
| 22 | "文字 AI 味重、emoji 多、图丑配色" | 没用用户口吻，图没参考 | 走 `renhua` 与 `post`；先看高质量海报与媒体写法 | 文案无破折号堆砌/空话金句；配图有参考卡 |
| 23 | "你问我这么多小事" | 把决策推给用户 | 只问口味/花钱对外/登录付款；其余自己定、做完告诉 | 提问前自检：属于这三类吗 |
| 24 | "你说完成了，其实没跑" | 没有运行证据 | 完成定义：验收证据+未验证部分+登记+状态更新 | 报告里"没验证的"一栏非空 |
| 25 | "视频后半段音乐没了" | ffmpeg `-shortest` 截断；未检查成片音频 | 先渲帧后一次性封装；核对时长 | `ffprobe` 音频时长 = 视频时长 |
| 26 | "我说的是风格化，你做成 pop art" | 取了最容易联想的标签 | 3 个差异化风格帧选一个；一个标签能概括=不够新 | 方向描述不能用一个熟悉词概括 |
| 27 | "示例只是启发，重点是我没说的" | 把例子当全部需求 | 研究整个品类，找出没说的，收拢成少数机制 | 研究表里"用户没提但关键的发现"≥3 条 |
| 28 | "名字 .com 被占 / 同名 App" | 先打分后检索 | 先检索淘汰再评分；以注册商页面为准 | `domain_check.py` 输出已附在 naming.md |
