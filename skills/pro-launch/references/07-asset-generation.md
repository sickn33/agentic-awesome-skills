# 07 素材生成

读完产出：`docs/asset-list.md`（每个素材：用途 / 谁生成 / 提示词 / 出处授权 / 处理方式 / 状态）。门槛：无代码画的角色；无来路不明素材。

## 分工
- **生图/素材交给生图能力**（Codex/其他图像模型/TapNow/Figma 的 generate_image）。Claude 写一份一次到位的 brief：要什么、几张、风格（引用参考卡的反推提示词）、输出路径、验收标准；同类合并一次调用。
- **代码只做**：排版、shader、程序化纹理、确定性效果。不用代码画人物、吉祥物、复杂线稿——"素材丑→成片一定丑"，这是被证实的。
- 真实照片：用户自己的 > 授权明确的库（Unsplash 等，记许可）。示范照片要多样（全身/半身/风景/不同性别肤色），不要 20 年前的手机照。
- 字体只用 OFL；音效可合成；Logo 草稿标"上线前重画"。

## 抠图 + 矢量化一条命令
```bash
bash scripts/cutout_vector.sh in.png out/            # Vision 抠主体(缩边2px) → vtracer 彩色矢量 → svgo
bash scripts/cutout_vector.sh in.png out/ --mono     # 单色图标/印章/马克笔线 → potrace
```
踩过的坑（输入比参数重要）：
1. **让生成器在纯色背景上出图**（纯白或纯品红），再去底；复杂背景抠不干净。
2. 要求"flat colour、无渐变、无投影、粗形状"；照片和渐变矢量化会变泥。
3. 抠图后**缩边**（脚本默认 2px），否则旧背景的蓝/白边会在矢量后变明显。
4. 在浅色和深色背景上都看一遍；1x 和 3x 各渲染一次；SVG 体积 >200KB 要调大 `filterSpeckle`。
5. 近景人像、脚被裁掉的照片抠图会失败：检测不到就走兜底（脸推人形），并在界面提示，别静默。
6. Vision 抠图需要 macOS 14+；人像用实例分割（iOS 17）作第二路径，默认设备失败时改用 CPU。

## 动效素材
- Rive MCP（事实）：`~/.claude.json` 里 `rive` 配置为本地地址 `http://127.0.0.1:9791/mcp`，需要 Rive 桌面编辑器在运行并开启 MCP 才连得上；未运行时会报 ECONNREFUSED。`.riv` 必须在编辑器里制作，不能靠写代码生成。没有编辑器时用 SwiftUI 动画做后备，保持同一套状态名，之后替换。
- Rive：角色状态机（idle/working/success/error/reducedMotion）。**.riv 要在 Rive 编辑器里做**（需要用户账号或社区 remix），代码侧只能写运行时与状态机接口——先做占位接口，.riv 到了替换，业务代码不动。只试一个资产（如保存成功的勾）再决定是否全量接入。
- Lottie/Spline/3D：没有明确收益前不引入；每引入一个库要写它换来的一个具体画面。
- Shader：从 Shadertoy/Codrops 移植思路到 Metal，不照搬 web 写法；纸纹颗粒只加在纸上、不加在用户照片上。
- 真手绘素材（箭头、星、圈、勾、胶带、纸）应有 ≥1 套亲手/生成的位图或矢量，避免全部来自同一程序多边形。
