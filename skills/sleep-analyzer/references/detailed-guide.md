# 睡眠分析器：数据解释与安全边界

本指南用于描述用户授权提供的睡眠日记或设备数据，不诊断失眠或呼吸暂停，不制定治疗或用药方案。没有捆绑数据、分析程序或经过验证的预测模型。原指南中的病例、任意权重质量/规律性分数和疗效数字没有验证依据，不能作为用户结果。

## 1. 确定范围与数据来源

确认日期范围、年龄适用性、时区、工作/轮班时间、数据来源和用户想回答的问题。儿童、孕期、轮班、已知疾病和药物影响需要适当专业评估，不能套用成人示例。仅在授权范围读取本地文件；`data-example/` 是上游示意路径，本包不提供这些记录。不要搜索或关联无关的健康数据，也不要上传到第三方。报告去标识化，保存和删除按用户要求。

睡眠日记与穿戴设备估计必须分列。设备的睡眠阶段和觉醒判断并非临床睡眠监测；跨设备/算法版本的变化可能来自测量差异。缺失夜晚不是零睡眠，未知不是正常。

## 2. 先检查数据

每晚记录完整带日期时间：上床、估计入睡、最终醒来、离床、估计夜间清醒时间，以及主观恢复感。验证时间顺序、跨午夜、夏令时、重复记录和单位。总睡眠估计应排除入睡潜伏期和夜间清醒时间；不能仅用起床减上床。

```json
{
  "date": "2025-06-20",
  "timezone": "Asia/Shanghai",
  "bedtime": "2025-06-20T23:00:00+08:00",
  "sleep_onset": "2025-06-20T23:30:00+08:00",
  "final_wake": "2025-06-21T07:00:00+08:00",
  "out_of_bed": "2025-06-21T07:15:00+08:00",
  "awake_after_onset_minutes": 30,
  "source": "self_report",
  "subjective_quality": "fair"
}
```

这是合成示例：卧床8.25小时、入睡后到最终醒来7.5小时、减夜醒0.5小时后估计睡眠7小时，效率约84.8%。公式为估计睡眠时间 / 卧床时间 × 100；报告定义和误差，不能把一个百分数当成诊断或治疗目标。

## 3. 描述趋势

报告有效夜数/预期夜数、缺失和来源。给出时长的中位数/范围或均值/标准差，并在同来源相近窗口比较。午夜附近的作息时间使用圆周统计或以固定锚点展开，不能把23:50和00:10平均成中午。

社交时差通常比较自由日与工作日的睡眠中点，需处理跨午夜和轮班；周末睡眠时长差不是同一指标。可报告分钟差而不制造0–100的“规律性医学分数”。描述趋势不能自动称为统计显著；需要实际模型、样本量、自相关和缺失处理。不要给出个人“最佳窗口”或保证改善百分比。

## 4. 问卷与症状

PSQI 和 STOP-Bang 仅在获得实际完整答卷、适用版本、计分说明和使用许可时讨论。不得从设备时长补造答案、改阈值或把缺失答案当阴性。PSQI涉及多个成分；未完整计分时不输出总分。STOP-Bang 是筛查而非诊断，不在此复制一个不完整的自制量表。原示例把“未观察到呼吸暂停”计为阳性、改变BMI阈值且总分不符，因此已移除。

记录入睡困难、频繁觉醒、日间疲劳、打鼾或憋醒等用户报告，但不要仅由30分钟或觉醒次数判定疾病。严重或持续困扰可随时联系专业人员，不必等满三个月。疑似呼吸暂停应由临床人员评估是否需要睡眠检查。

## 5. 关联分析

只有在用户同意后关联运动、咖啡因、饮食或情绪数据。按实际日期/时区对齐，报告样本数、滞后定义、缺失处理和效应大小。连续观测常有自相关；普通Pearson p值可能不适用。多重比较、季节/周末、疾病和药物可混杂结果。常量序列、少量配对或非有限数据不计算相关。

一个r值不能证明因果、双向机制、临床重要性或未来疗效。将结果写为“在本观察窗口相关，尚不能归因”，而不是“下午两点后咖啡因显著导致失眠”。

## 6. 建议与升级

可以讨论用户可接受的低风险睡眠卫生习惯：规律的起床安排、舒适安静的睡眠环境、放松活动、记录可能影响睡眠的因素。具体时间和环境偏好按个人情境讨论，不承诺睡眠时长/PSQI改善数字。不要强制限制液体、调整药物、使用酒精助眠或给出固定睡眠限制处方。

长期失眠的CBT-I应由合格人员或适当的临床方案指导；本技能不独立实施睡眠限制。明显嗜睡时避免驾驶或危险操作并寻求及时医疗建议。急性呼吸困难、失去意识等紧急症状联系当地急救服务。

## 验证清单

检查跨午夜/夏令时、重复/缺失夜、清醒时间扣除、效率分母、常量序列与小样本。任何示例必须标为合成，不能输出不存在的原始记录、问卷分数、显著性或治疗预测。
