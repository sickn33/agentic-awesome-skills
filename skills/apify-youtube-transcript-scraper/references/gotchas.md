# Gotchas — harshmaur/youtube-transcript-scraper

## What `maxVideos` limits

| Input | `maxVideos` applies? | Ceiling |
|---|---|---|
| `videoUrls` | No. Every link is read. | none |
| `channelUrls` | Yes, per channel, newest first | the channel's uploads |
| `playlistUrls` | Yes, per playlist | about 100 |

`dateFrom` and `dateTo` filter the videos that `maxVideos` already picked. For "every video from 2024" on an active channel, set `maxVideos` high enough to reach back to 2024, and estimate the cost on that number.

## Captions and languages

- `availableLanguages` lists the caption tracks of the video. A code can show twice: one manual track and one auto-generated track.
- Without `language`, the row uses the video's main caption track.
- With `language`, a matching track wins. Otherwise YouTube translates the transcript, and `wasTranslated` is `true`. When translation is not available, the row keeps the original language.
- Auto-generated captions (`isAutoGenerated: true`) can be wrong on names, numbers and technical words.

## Numbers

- `viewCount`, `likeCount`, `commentCount` and `subscriberCount` are numbers at the time of the run.
- `subscriberCount` and `commentCount` are rounded the way YouTube shows them (for example 21,400,000).
- `channelThumbnail` can be `null`.

## Row size

`both` keeps the segments and the full text, so a one-hour video gives a large row. Use `text` when the agent only reads the words. Large results can fill the context window; save them to a file and read parts.

## MCP connector delivery

| Field | Meaning |
|---|---|
| `mcpConnector` | Connector ID that the user created in Apify Console. |
| `mcpTarget` | Slack channel, Notion page or database, or Google Sheet ID. |
| `mcpMode` | `perPost` (one message per video, default) or `summary`. |
| `mcpMessage` | Template with `{{field}}` placeholders. Default `*{{title}}* — {{channelName}}\n{{url}}`. |
| `mcpMaxItems` | Most transcripts to send. Default 50. |

A delivery problem never fails the run.
