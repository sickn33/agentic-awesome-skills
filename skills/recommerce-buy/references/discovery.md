# Bounded second-hand discovery

Use this guide when live read-only search is available. Supplied-shortlist assessment does not require a discovery phase. Adapt the steps to the actual tool schemas and the user's request; do not invent providers, filters, category IDs, or capabilities.

When using Budna's public Explore tools, read [the Budna notes](budna.md) for its price-filter, category, auction, shipping, and fee-field limits. Other providers do not require that reference.

## Search with enough recall

Start from the intended use and a small set of concrete search terms. Where the buyer names an exact model, preserve its variant and meaningful suffixes. Where the buyer names an outcome, identify only the capabilities needed for it before searching. A familiar product family is not a substitute for requirements.

Use the marketplace and language appropriate to the buyer's location. Search local terms and useful synonyms if the first query misses plausible listings. A listing may omit a structured attribute or use an unexpected category; applying every desired attribute as a filter can hide good candidates. Use only verified filters, then check missing details in the listing.

Use price filters to reduce irrelevant results, not to prove affordability. Item-price search results may exclude fees, accessories, delivery, or collection costs. If a tool accepts only whole major-currency units, choose a broad enough supported search ceiling and apply the buyer's exact decimal boundary to the actual costs afterward. Never round the buyer's budget up in the recommendation.

For an ordinary shortlist, a small first page and detailed inspection of the strongest few candidates is a useful starting point. Explore another query or page only when it could change the result: too few plausible items, systematic missing attributes, uncertain duplicates, or a material price/fit tradeoff. Respect tool limits and any user budget; do not scrape a whole market to fill a short table.

If the first query is weak, change one search dimension at a time: a synonym, a broader category, fewer optional filters, or a different supported sort/search mode. Keep hard budget, delivery, compatibility, and deadline requirements intact. A wider collection radius or relaxed condition requirement is a buyer decision, not an invisible fallback.

## Inspect and deduplicate

Search summaries are leads. Fetch the strongest candidates' current detail and relevant attributes before ranking them. For a blocked detail page, say what remains unavailable; do not fill the gap from memory or treat an access failure as proof that the item sold. Separate an empty successful search from a failed request, unavailable filter, or truncated result set.

Use stable listing IDs or canonical listing URLs to identify repeated results. Normalize only tracking fragments or parameters known not to identify the offer. Similar titles or reused photographs alone do not prove identical inventory. Mark likely cross-posts as uncertain and do not count them as independent alternatives until the offered units are distinguishable.

Check exact-model claims using primary product documentation where available. A retailer's summary, seller's assertion, or related model page may help locate a specification but does not establish a decisive compatibility fact. Keep evidence collection proportional: stop inspecting an option after a confirmed hard mismatch unless the buyer asked for a broader comparison.

## Finish honestly

Stop when enough distinct candidates support a useful decision and further searches are unlikely to change it. If the bounded search finds no suitable option, explain the main bottleneck and the most useful next move. Do not manufacture a recommendation; offer the specific preference the buyer could reconsider or the missing fact that would unlock the search.

Refresh the best actionable candidate before presenting a live shortlist. If that candidate is no longer available, check the next candidate rather than repeatedly retrying the same stale page. Respect rate limits; a transient failure is not permission for unbounded retries.

State actual coverage: sources used, important queries or filters, whether results were truncated, and which decisive facts remain unchecked. Multiple results from one source do not establish a market-wide minimum. Sponsored or featured placement is not evidence of suitability, condition, or value.
