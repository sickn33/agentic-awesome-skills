# Common Pitfalls


- **Problem:** a static mapping is described as a completed workspace build.
  **Solution:** deliver manual mappings without a connection; claim a live change only
  after the authorized tool operation succeeds.
- **Problem:** asked all five questions in one message.
  **Solution:** ask one, wait, and drop any the first answer already covered.
- **Problem:** one homepage trying to rank for six services.
  **Solution:** one page per service, one primary keyword each. This is the single biggest
  structural win for a small local business.
- **Problem:** the NAP is written slightly differently on three pages.
  **Solution:** copy the canonical block. Do not rephrase it for readability - consistency
  is the signal.
- **Problem:** the site is fast on a laptop and unusable on a phone.
  **Solution:** test on a mid-range Android, not a new iPhone. Compress the images first;
  they are almost always the cause.
- **Problem:** a blog was added and has three posts from 2023.
  **Solution:** either commit to writing or remove it. Do not leave a thin archive.
- **Problem:** schema was marked up but never validated.
  **Solution:** `Structured Data Valid` stays false until the Rich Results Test passes. An
  invalid schema block is worse than none.
- **Problem:** the meta description was auto-generated and reads like a robot wrote it.
  **Solution:** it is a sales line under a search result, written by a human, 140-160
  characters.
- **Problem:** the old site had traffic and the rebuild lost it.
  **Solution:** a redirect map from every old URL to its new equivalent, checked before
  launch. The developer task, not the copy task.
- **Problem:** all four artifacts drift apart.
  **Solution:** derive all four from the field list in this file, never by hand.
- **Problem:** Notion import shows every column as Text.
  **Solution:** that is expected. Apply the property mapping table once, after import.
