# 烘云托月法

- 定义：通过环境、旁人反应、侧面描写或外部轮廓突出主体。
- 适用文章类型：案例叙事文章、公共评论文章、答复体文章。
- 解决的问题：直接写主体不够有力，或主体不宜过早正面出现。
- 操作步骤：先写周围反应或环境；让主体从侧面显出；再点明主体意义。
- 本卡操作建议：本技法的关键不是记住名称，而是把“通过环境、旁人反应、侧面描写或外部轮廓突出主体”落实到材料选择和段落位置上；执行时按“先写周围反应或环境；让主体从侧面显出；再点明主体意义”推进。
- 段落动作：在成文时先标出它负责的段落位置，再用它解决“直接写主体不够有力，或主体不宜过早正面出现”；该技法至少要完成一个可见动作，如立题、入场、串联、转折、反驳、回落或收束。
- CrossFrame 适配：只改变表达路径，不改变事实边界、判断档位、来源台账、连续联读包、读态胶囊和源锚点。若技法产生的新句子无法回指底稿，应降为表达转译或删除。
- 来源边界：上游提及《文章写作技法》及 OCR 笔记，但本包未提供作者、版次和可复核原页；本卡只作为社区写作建议，不声称已核验原书页码或作者原意。
- 好句类型：侧面托举句：不直写主体，先写环境、反应或旁证。
- 段落前后关系：前接局部材料或整体背景；使用它处理点面、虚实、多寡、动静关系。后接边界段、机制段或概念上升，保持对照和转化有现实落点。
- 文章类型微用法：中性分析长文用它处理复杂材料；公共评论用它兼顾局部案例和制度面；思想文章用它保留余味；组织复盘用它避免单线归因。
- 本卡失败提示：失败时会把对照、留白或象征写得含混，导致中心命题和责任链消失。
- 文章类型用法：适用于案例叙事文章、公共评论文章、答复体文章。优先用于复杂关系、点面互照、含蓄表达或边界段，让判断保留层次和余地。
- 失败形态：托衬不能遮蔽主体；常见失败是为了好看而让技法接管命题、让比喻替代证据，或让段落动作越过胶囊边界。
- 搭配技法：以宾衬主法、意在言外法、象征寓意法。
- 误用风险：托衬不能遮蔽主体。
- 输出自检：侧面材料是否让主体更鲜明？

- 非虚构边界：不得编造场景、人物内心、引语或因果以增强文采；虚构和合成例须明确标注。修辞不能压过反证、隐瞒关键限制，单例不能自行证明普遍规律。
