# 欲露先藏法

- 定义：先隐藏题旨、性格或真相，待火候到时再揭示。
- 适用文章类型：案例叙事文章、答复体文章、公共评论文章。
- 解决的问题：主题过早亮出，缺少发现感。
- 操作步骤：先写现象或误解；保留关键因果；在转折处揭示真实结构。
- 本卡操作建议：本技法的关键不是记住名称，而是把“先隐藏题旨、性格或真相，待火候到时再揭示”落实到材料选择和段落位置上；执行时按“先写现象或误解；保留关键因果；在转折处揭示真实结构”推进。
- 段落动作：在成文时先标出它负责的段落位置，再用它解决“主题过早亮出，缺少发现感”；该技法至少要完成一个可见动作，如立题、入场、串联、转折、反驳、回落或收束。
- CrossFrame 适配：只改变表达路径，不改变事实边界、判断档位、来源台账、连续联读包、读态胶囊和源锚点。若技法产生的新句子无法回指底稿，应降为表达转译或删除。
- 来源边界：上游提及《文章写作技法》及 OCR 笔记，但本包未提供作者、版次和可复核原页；本卡只作为社区写作建议，不声称已核验原书页码或作者原意。
- 好句类型：迟揭句：先让材料自行积累，到合适处揭示主旨。
- 段落前后关系：前接读者已经理解的表面解释；使用它制造合理起伏。后接揭示、降档、反向条件或责任链，不让波澜变成戏剧化断言。
- 文章类型微用法：评论和论辩中用它制造认知转折；趋势推演中用它展开分支；案例叙事中用它保留阅读张力；答复体只轻用，避免制造焦虑。
- 本卡失败提示：失败时会为了起伏制造悬念、反转或戏剧性，把待核验内容写成事实。
- 文章类型用法：适用于案例叙事文章、答复体文章、公共评论文章。优先用于开篇抓手、转折、递进或中段反差，让文章有起落但不失焦。
- 失败形态：藏要有火候，露要自然，不能拖延；常见失败是为了好看而让技法接管命题、让比喻替代证据，或让段落动作越过胶囊边界。
- 搭配技法：故设悬念法、曲径通幽法、卒章显志法。
- 误用风险：藏要有火候，露要自然，不能拖延。
- 输出自检：揭示后是否让前文重新获得意义？

- 非虚构边界：不得编造场景、人物内心、引语或因果以增强文采；虚构和合成例须明确标注。修辞不能压过反证、隐瞒关键限制，单例不能自行证明普遍规律。
