# Lessons — what got rejected, what got accepted (one real build, 7 rounds)

Read at step 4 (before building) and step 7 (review). Each line is a past failure or win.

## Rejected
- Gradient cards, receipts, collages, IOU paper, constructivist posters → "ugly / looks AI-made". **Any composed "design scene" reads as AI**, whatever the art style.
- Emoji, bullet lists, slogans in the copy → "AI 味".
- A chat mock that is only roughly like the app → "doesn't look like Claude". Mocks must match the real app (check its App Store screenshots first).
- Everything mid-size, timid tints → "too 正经 / a bit ugly".
- Copy that is all facts, no play → "太正经了". But the fix that followed (jokes on every frame, space-separated fragments) → "完全不人话，读起来都不通顺……幽默偶尔有一下就行，不然显得油腻". Right balance: fluent full sentences, at most one joke and one 金句 per set, at most two handwritten asides.
- A fact that wasn't true ("deleted the tools and restarted") slipped into a headline. Every claim gets checked against the real record.

## Accepted
- Real screenshot + thick-outlined vlog subtitle with a yellow keyword → "挺网感的".
- Pixel-faithful phone UI mocks (X post, Claude chat, lock screen, Google, Stripe) using only true facts.
- App Store screenshot-poster layout: one headline, one phone, one floating card → "还不错".
- Series lockup + DAY tag + progress bar on every frame; a full-bleed accent page with one giant number; product pages with a real output and a price pill; a follow hook at the end.

## Craft that separated a "very good" deck from ours (same chart skill, better hands)
- Extreme scale contrast: hero number 200px+, labels small and grey. Kill middle sizes.
- Confident color: a whole page in the accent, not pale tints everywhere.
- Real artifacts as objects: big cards, deep soft shadows, slight tilt — never flat crops.
- Story + evidence + number in one frame.
- Heavy system font (PingFang / -apple-system 800–900) for CJK headlines.
