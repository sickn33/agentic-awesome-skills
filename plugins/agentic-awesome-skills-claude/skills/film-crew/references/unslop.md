# Unslop: why AI video looks like AI video, and what to write instead

| Slop signal | Usual cause in the prompt | Write instead |
|---|---|---|
| Plastic, poreless skin | "beautiful", "flawless", "perfect skin" | "visible pores, slight shine on the forehead, faint under-eye shadows" |
| Everything evenly lit | no light source named | a motivated key ("hard sun through blinds, camera-left") and deep shadows |
| Floaty slow-motion drift | no speed given, "cinematic" | real-time speed, or a stated speed ("normal speed", "2x slow motion") |
| Camera wandering aimlessly | no camera instruction | one named move, or "locked-off tripod shot" |
| Morphing hands / objects | complex hand action, wide framing | tight framing, simple grip, one object, slow action |
| Faces changing between shots | paraphrased character descriptions | verbatim continuity-bible descriptors, or image-to-video from one reference |
| Oversaturated, HDR-ish color | "vibrant", "8k", "ultra HD" | a film look ("Kodak Portra 400, soft contrast, fine grain") and a limited palette |
| Symmetrical stock-footage framing | no composition choice | a lens, an angle and an off-center subject ("subject in left third") |
| Gibberish text | signage, labels, UI in frame | no readable text in frame; add text in the edit |
| Nothing actually happens | a mood instead of an action | one visible, physical action with a start and an end |

## Words that add nothing

`stunning, masterpiece, best quality, 8k, 4k, ultra-detailed, hyper-realistic, award-winning, trending, epic, cinematic (alone), breathtaking`

Delete them. They don't hurt much on their own, but they push out words that would help.

## Words that tend to help

- A **lens** (24mm, 50mm, 85mm, macro)
- A **camera move** (slow push-in, locked-off, handheld)
- A **light source** (window light, sodium streetlight, overhead fluorescent)
- A **film stock or look** (35mm film grain, Super 8, VHS camcorder, iPhone front camera)
- **Imperfection** (scuffed, fingerprints, wrinkled, condensation, frayed)
- **Real-time physics cues** (splashes, drips, recoils, bounces)
