# Common Pitfalls


- **Problem:** a static mapping is described as a completed workspace build.
  **Solution:** deliver manual mappings without a connection; claim a live change only
  after the authorized tool operation succeeds.
- **Problem:** asked all five questions in one message.
  **Solution:** ask one, wait, and drop any the first answer already covered.
- **Problem:** a code of conduct that says "report to the manager", where the manager is the
  subject.
  **Solution:** name an independent recipient before the policy is written. A reporting
  route that dead-ends is worse than none, because it teaches people not to report.
- **Problem:** the signature sheet is the record of understanding.
  **Solution:** `Understood` is a conversation. A signature proves a PDF was opened.
- **Problem:** the complaint was resolved with an apology and nothing was written down.
  **Solution:** record it, with `Closed - no further action`. In six months the same
  complaint is the second incident, and nobody can prove the first was handled.
- **Problem:** a 40-page handbook nobody has read.
  **Solution:** two pages in plain language, read at induction. Length is not rigour.
- **Problem:** the policy, the data protection notice and the acceptable use rules are all
  in one document.
  **Solution:** five documents, five owners. Folded together, none of them is applied.
- **Problem:** someone wants this skill to decide whether a complaint is justified.
  **Solution:** it cannot, and it must not. The register records that a process happened and
  who ran it. The decision belongs to a person under the business's procedure.
- **Problem:** the register has names in it and is shared with an accountant.
  **Solution:** use employee references, and restrict access to conduct records.
- **Problem:** all four artifacts drift apart.
  **Solution:** derive all four from the field list in this file, never by hand.
- **Problem:** Notion import shows every column as Text.
  **Solution:** that is expected. Apply the property mapping table once, after import.
