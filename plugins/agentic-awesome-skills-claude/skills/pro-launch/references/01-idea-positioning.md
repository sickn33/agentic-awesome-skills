# 01 想法与定位

读完产出：`docs/positioning.md`。门槛：一句话讲清和谁不同；至少一个数字来自实查。

## 做法
1. **先把用户的话当种子。** 用户说"打孔照片"，他真正要的是"图像创作品类里不断换新的玩法"。先问自己：他没说的是什么？（品类、周期、变现、增长回路）
2. **品类一句话**，格式：「像 X 的 Y，但只做 Z」。例：图片版的"视频模板库"：用户把照片放进正在流行的玩法，一键得到可发布的图。
3. **相邻品类对比表**（3–6 行）：品类 / 代表产品 / 和你的区别。别把"可选内容"当竞品（复古相机是你的一个玩法，不是对手）。
4. **趋势地图**：近 5 年同类 trend 的时间、地区、触发点（谁引爆的），区分"工具触发"（某模型出新能力）和"文化触发"（线下大头贴回潮）。
5. **空白判断**：用目标市场语言的搜索词在各国 App Store 搜一遍（`scripts/appstore_refs.py` 或 iTunes Search API 取评分数作粗代理）。结果只能写"有限搜索词下没找到"，不能写"市场空白"。
6. **商业化先验证有人付钱**：一个产品、一个渠道、一个价格、一个周期；先查有没有免费平替，有就别做付费版。伪需求的信号：定价没有购买欲、只有"感觉有用"。
7. **开源与赚钱**：开源是拿热度与资源的手段，不是收入；App Store 付费版可以和开源并存（许可证与素材授权先理清，见 12）。

## 数据标注（防止印象变事实）
每个数字后标：【实查】工具实测 / 【网】网上来源（附链接）/ 【判】我的判断 / 【缺】没查到。**【判】不得写成结论。**
