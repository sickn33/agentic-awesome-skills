# Common Pitfalls

- **Problem:** a static mapping is described as a completed workspace build.
  **Solution:** deliver manual mappings without a connection; claim a live change only
  after the authorized tool operation succeeds.
- **Problem:** asked all five questions in one message.
  **Solution:** ask one, wait, and drop any the first answer already covered.
- **Problem:** a font chosen because it is free, with the licence never opened.
  **Solution:** read the licence, name it in `Licence Type`, and record the source and date.
  Many free fonts permit personal use and forbid commercial use - which is the business's
  case.
- **Problem:** a logo assembled from a free icon pack.
  **Solution:** do not. It is not distinctive, the icon's licence may forbid logo use, and
  another business is likely using the same one. Pay for this one, or design it.
- **Problem:** a stock photo of a recognisable person used without a release.
  **Solution:** check the model release, or use a source that does not need one. This is the
  most common way a cheap image becomes a legal problem.
- **Problem:** a free tool chosen, and the work now only exists inside it.
  **Solution:** check `Export Format` and `Vendor Lock-In Risk` before starting. Anything
  the business owns must leave in an open format.
- **Problem:** "free forever" assumed, and the tool now requires a card or has cut its
  exports.
  **Solution:** `Verified On` is the evidence. Re-verify at renewal and when the business
  changes scale.
- **Problem:** attribution forgotten on a `CC BY` asset.
  **Solution:** record the required wording in Notes at selection, and check the published
  work, not the source folder.
- **Problem:** a free template used for a client website without checking the template
  licence.
  **Solution:** a template's licence governs the site built with it. Verify before shipping,
  and record it in `business-website-setup` too.
- **Problem:** six free tools, none of them used.
  **Solution:** one tool per job, and consolidate. An unused subscription is a real cost
  whether or not it is free.
- **Problem:** accessibility checked after the design was finished.
  **Solution:** check type size, contrast and alt-text support at selection. It is a
  property of the asset and cheaper to choose than to fix.
- **Problem:** all four artifacts drift apart.
  **Solution:** derive all four from the field list in this file, never by hand.
- **Problem:** Notion import shows every column as Text.
  **Solution:** that is expected. Apply the property mapping table once, after import.
