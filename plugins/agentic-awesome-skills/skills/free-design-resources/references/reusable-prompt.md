# Reusable Prompt

```
I need to know which free design tools, fonts, icons and images we can use without
getting into trouble, and which ones we should pay for instead.
Ask me one short question at a time, and only about what I have not already told you.
Never invent a licence, a price, a feature or an export format. If the terms have not been
read from the provider's own current terms, mark it Unverified and say so. Prefer things we
can export in an open format and keep a copy of. Check accessibility at the point of
selection. Wait for me to ask before you build it.
When I ask, output CSV, SQL DDL, JSON Schema and a Notion property mapping. Data only.
```
