# 示例库：小红书真实爆款怎么说话（2026-10 采集）

用法：写标题/正文前先扫一遍，学**结构**，不抄原句。数字是点赞数。
采集方法：小红书网页搜索关键词 → JS 抓 section.note-item 的 .title 和 .count → 点开高赞看正文。以后定期补。

## 一、标题结构（按效果排）

**1. 反差 / 自嘲**（最稳）
- 现在年入百万了，居然还要上早八 · 6902
- 算了，AI说啥我做啥吧 · 3724（正文就两句废话 + 十个梗标签，靠视频字幕撑）
- vibecoding了个没用的东西
- 我以为我vibecode很赚了，但竞对赚20倍… · 647
→ 公式：一个很大的事 + 一个很小很日常的落差。或者干脆认怂。

**2. 身份 + 挑战 + 期限**
- 普通大学生挑战吃一波AI红利！ · 1.6万（正文：04年 港科大读研 上个月开一人公司 第一个月有单了 再给自己3个月 挑战100万）
- 72小时AI生存挑战｜大学生挑战用AI赚到钱 · 232
- 我给AI 500块，看它能不能养活我 · 8（同题材，但没身份没反差，就没量）
→ 关键是"普通 + 具体身份 + 具体数字 + 期限"，正文像跟朋友交代近况。

**3. 我做了个 X，实测/结果**
- 我给6个AI做了共享记忆，实测一周 · 4288
- 纪念一下我的第一个 GitHub 万星项目 · 4293
- AI 写了上万行代码，给 aespa 做了支 MV · 8699
- AI把美剧里的破案墙做出来了！ · 1261
→ 动作具体、对象具体，"实测一周""纪念一下"这种随口词让它不像广告。

**4. 一句话梗 / 画面感**
- 把人生喂给AI，挖掘薪资天花板 · 4.7万
- AI在小县城能有多下沉 · 4.7万
- 新加坡用claude code的人比新加坡人都多 · 1229
- Opus5.5把"瘫坐长椅原子弹爆炸"做成了动画 · 1623
→ 夸张但不喊口号。

**5. 诗意短标题**（vibecoding 圈的作品向）
- 雨镜 · 6989 ／ 月光中的想念 · 6.8万 ／ 拾不起来的时间 · 2819
→ 作品本身好看才成立，日记帖不用。

## 二、两种口吻对照

**大学生口吻**：自报家门（几年生、哪读书、大几）、"普通""挑战""哈哈哈"、感叹号偶尔一个、坦白目标（"当然能净赚到100万那就更好了哈哈哈"）、标签里带 #大学生搞副业 #搞钱。
- 暑假用AI接了点私活，没想到还真有人买单 · 266
- 文科生因为vibecoding意外得到offer接吗？ · 2647
- 杭州大二｜月入一万美金的同龄人都在做什么 · 220

**科技自媒体口吻**：信息差 + 判断，短，带模型/工具名，敢下结论，偶尔夸张情绪但很具体。
- Codex磨几十轮，不如Claude Code做一天？ · 421
- Anthropic 刚公开了 Claude Code使用技巧 · 678
- 我真的受不了了，兴奋得我只睡了 3 小时！ · 784
- 如题 · 610（标题就俩字，靠封面）
- AI coding 很火，但大多App不赚钱 · 207

**Jack 自己的版本** = 科技自媒体的判断力 + 大学生的坦白和自嘲，句子用他的空格节奏（见 SKILL.md）。

## 三、正文结构（高赞帖共性）

- 第一句交代"我是谁 + 在干嘛"，不铺垫。
- 中间只讲一两件具体的事，带一个具体数字。
- 结尾是下一步计划或一句自嘲，不升华。
- 标签可以玩梗（#也不是不行 #多少有点离谱 #让大家见笑了），比 #AI #干货 有人味。
